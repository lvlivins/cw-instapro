# Instapro 

MVP социальной сети для обмена фотографиями

## Первоначальная оценка

50 часов

## Фактически затраченное время

88 часов 

## Реализованная функциональность

Рендер постов из API<br>
Получение списка постов с сервера<br>
Получение постов конкретного пользователя из API<br>
Страница с фотографиями отдельного пользователя<br>
Авторизация и регистрация пользователя<br>
Проверка авторизации пользователя<br>
Добавление нового поста через API<br>
Удаление поста через API<br>
Добавление и удаление лайка<br>
Отображение актуального количества лайков<br>
Переход на страницу пользователя по клику на автора поста<br>
Загрузка изображений при создании поста<br>
Сохранение пользователя в localStorage<br>
Выход из аккаунта<br>

## Доп фичи 

Модальное окно подтверждения при удалении поста<br>
Модальное окно с предложением авторизации при неавторизанном профиле<br>
Наведения на кнопки подсвечены<br>
Использование библиотеки date-fns<br>
