# Instapro
MVP социальной сети для обмена фотографиями

## Первоначальная оценка
50 часов

## Фактически затраченное время
88 часов 

## Реализованная функциональность
Рендер постов из API
Получение списка постов с сервера
Получение постов конкретного пользователя из API
Страница с фотографиями отдельного пользователя
Авторизация и регистрация пользователя
Проверка авторизации пользователя 
Добавление нового поста через API
Удаление поста через API
Добавление и удаление лайка
Отображение актуального количества лайков
Переход на страницу пользователя по клику на автора поста
Загрузка изображений при создании поста
Сохранение пользователя в localStorage
Выход из аккаунта

## Доп фичи 
Модальное окно подтверждения при удалении поста
Модальное окно с предложением авторизации при неавторизанном профиле
Наведения на кнопки подсвечены
Использование библиотеки date-fns 
Адаптивная верстка 
Улучшен UX/UI взаимодействия
